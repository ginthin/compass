Add tools only when it hurts · not before

The phased upgrade (each has a clear trigger).

PHASE 1 · NOW

Attio + Gmail + hand-posting + Norte

Launch on this. Zero new tools. Everything Norte drafts, you send/post. This is enough to run the whole 5-week sprint if you want.

PHASE 2 · when posting by hand gets annoying

+ Buffer (schedule social)

Trigger: you're posting 4+ times a week and doing it live is a chore. Buffer just queues them so they auto-post at set times. ~20 min to set up once. Optional.

PHASE 3 · when there's real email volume

+ Mailchimp (newsletter + automated sequences)

Trigger: you have a real list (100s) and are sending the monthly newsletter + want the signup sequences to run automatically. Until then, personal Gmail wins. Later, not now.

The principle: don't buy or wire up software to solve a problem you don't have yet. Start manual, add automation only where the manual version genuinely hurts. This is how you stay in control and not overwhelmed.

The signup fix · with the simple stack (no scary automation)

Your #1 growth win, done simply.

The analysis called this the fastest, lowest-effort growth opportunity — and you can do it with just Attio + Gmail + Norte, human-sent at first. No automation software required.

STEP 1

See who's in the hole

Aidar sends the signup export → Norte scores everyone → you get a ranked list of who's worth contacting.

STEP 2

Norte drafts, you send

For each warm signup, Norte writes a personal email with their context. You send it from Gmail. Human, not a blast.

STEP 3

Automate later

Once you see which messages work, THEN we set the winners to send automatically (Mailchimp or a lifecycle tool). Prove it by hand first.

Quality over quantity: max ~4 touches in 3 weeks, each genuinely useful. The moment someone replies, a human takes over. Fewer, sharper, better-timed — never a spray.
