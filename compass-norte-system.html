Compass Labs · The Norte System 🧭

The plugin, the master doc,
and where everything lives.

How Norte is built and where all of it is stored. Written so anyone, including the CTO, can see there is no black box: the brain is a file you own, the data is in your own tools.

1 · THE BRAIN · the skills

Norte is 15 skills. They live in two places you control.

THE PLUGIN

norte.plugin (v0.2.1)

A single file that bundles all 15 skills. Install once, the whole team gets Norte in their Claude. It is a file you own and can share. Reinstall the new version when we update it.

THE MASTER DOC · source of truth

Compass-Skills (xlsx + md)

The one source of truth for every skill: name, description, and the full prompt. The plugin is generated from this. If they ever disagree, the master doc wins.

The rule: the master doc is the single source of truth. The plugin is built from it. Never edit the plugin by hand. Change the master, rebuild the plugin, reshare. That keeps everyone in sync and every change traceable.

3 · HOW NORTE REMEMBERS AND LEARNS

No hidden brain. The memory is the skill files.

Norte does not silently evolve on its own. It gets better through one visible, versioned loop, and you control every step.

feedback in #norte-feedback→ edit the master doc→ rebuild the plugin→ team reinstalls

So Norte's "memory" is just the current version of the skill files. Every improvement is a change you can see, review and roll back. Cowork also keeps a small project memory note for continuity between sessions, but the source of truth for how Norte behaves is always the master doc.

4 · FOR THE CTO

Data ownership, in plain terms.

The short version: Norte's data lives in Compass's own Slack and Google Drive. Its instructions live in a plugin file and a master doc that Compass owns and can export at any time. Claude (Anthropic) does the processing at request time, but the record of truth, the plans, the content and the feedback, all sit in your own tools. Nothing is locked in a black box, every skill change is versioned and reversible, and you can walk away with the plugin file and the Drive folder and keep everything.
