Make a new Nova episode

One engine, one locked voice. Change the script, get a new voiced video. This preview runs a sample script.

How to make a new episode (≈ 10 min)

  1. Write the script — one short line per scene (Norte does this from the topic bank + claims).
  2. Make the voice — ask Norte: “generate Nova’s voice for [episode]”. It uses the locked voice (voice_id 21m00Tcm4TlvDq8ikWAM = Nova) so every episode sounds the same. Save the clips as scene1.mp3 … sceneN.mp3 in nova-vo/[episode]/.
  3. Duplicate this file → compass-nova-video-[episode].html.
  4. Edit only the scenes array below (the one block). Set each scene’s ost (big line), cap (what she says), and au (the mp3 path).
  5. Open it → ▶ Play. Nova narrates in her voice, synced. Screen-record (system audio on) for the MP4, or hand the script + voice to HeyGen for an avatar cut.
// ⬇︎ THE ONLY THING YOU EDIT PER EPISODE var scenes = [ { ost:"Big line on screen", cap:"What Nova says out loud.", au:"nova-vo/episode/scene1.mp3" }, { ost:"Next big line", cap:"Her next line.", au:"nova-vo/episode/scene2.mp3" } // add as many scenes as the script has ];
Rules baked in: never write the word “live” (say “up and running in days”); non-custodial describes the architecture, never “safer”. Every line comes from the approved claims. If audio is missing, the browser reads the line so it always talks.
