Part A · Set up the machinery · ~2–3 hours total, this week

Three setups, in order. Then you're live-ready.

Do these top to bottom. Each is small. Check them off as you go.

A1

Attio — make it measurable

~30 min
Add 5 fields to the Companies object (Attio → Settings → Objects → Companies → Attributes → + New attribute). Create each:
  1. Segment — type: Select · options: Wallet, Stablecoin app, Neobank, Exchange, Broker/Wealth, Payments/Remittance, RWA issuer, AI-native, Other
  2. Country — type: Select (or Text) · e.g. Mexico, Argentina, Colombia, Nigeria, Kenya, US, Other
  3. Product interest — type: Multi-select · options: Earn, Credit, Trading, RWA, Agentic
  4. Source campaign — type: Text · (you'll tag it like 202608-earn-latam)
  5. Deal value — type: Currency (USD)
Then create your list:
  1. Attio → Lists → + New list → name it [Gin] LATAM sales → parent: Companies.
  2. Add your 5 LATAM targets to it (Littio, Belo, DolarApp, Ripio, Decaf) so it's not empty.

Why: these 5 fields are what let us answer "which segment/campaign created pipeline" later. Without them we can't measure. With them, everything is trackable. Stuck? Paste me a screenshot and I'll tell you exactly what to click.

A2

Mailchimp — build the audience + the campaign email

~60 min
Step 1 — one Audience, tagged by segment:
  1. Mailchimp → Audience → if you don't have one, create a single Audience called Compass Contacts. (One audience, not many — you segment with tags.)
  2. Import your contacts (export from Attio → CSV → import). Map columns to fields: email, company, and add a column for Segment and Country.
  3. Create Tags: LATAM, Africa, Stablecoin-app, Wallet, Signup. Tag contacts as you import. Tags = how you send to the right slice.
Step 2 — build the campaign email (the Earn diagnostic, LATAM):
  1. Mailchimp → Campaigns → Create → Email → Regular.
  2. To: your Audience, filtered by Tag = LATAM + Stablecoin-app (this is why tags matter — you send only to the right people).
  3. Subject + content: paste the email from Part B below. Keep it plain-text style (it feels personal, converts better than a designed template).
  4. Don't send yet — save it as a draft. It goes out on Day 4 of the launch.

Rule: Mailchimp is ONLY for the segmented campaign email + (later) the monthly newsletter + automated signup sequences. Your personal 1:1 outreach (Tier A/B openers) goes from Gmail, not Mailchimp — those convert far better sent by a human.

A3

A simple tracking sheet (instead of Buffer, for now)

~15 min
Make one Google Sheet, tab "Launch tracker", columns: Date · Channel · Post/asset · Link (with UTM) · Result (replies/clicks/meetings).
UTM — add this to every link you share (so Attio/GA can see the source)?utm_source=x ?utm_source=linkedin ?utm_source=mailchimp &utm_campaign=202608-earn-latam Example: compasslabs.ai/blog/earn?utm_source=linkedin&utm_campaign=202608-earn-latam

Buffer: you said contract it last — perfect. Until then you post by hand (5 min, 2×/week) and log it in this sheet. When posting by hand feels annoying, contract Buffer and it just auto-posts your queue. Not a launch blocker.

That's the whole machinery. Attio measures, Mailchimp sends the campaign email to the right slice, Gmail sends the personal ones, you post the social by hand, and I draft everything. Done. You're live-ready.
