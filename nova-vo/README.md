## How to get the 6 files (2 min)
The voice was already generated in **ElevenLabs** (voice: warm female narrator, "Rachel"). To download:

1. Go to **elevenlabs.io → History** (left sidebar).
2. You'll see the 6 newest items (the lines above). Click the **download** icon on each.
3. Rename them **scene1.mp3 … scene6.mp3** in this exact order (top line = scene1).
4. Drop all 6 into this `nova-vo/` folder.
5. Open `compass-nova-video1.html`, press ▶ — Nova now narrates, synced.

That's it. If the files aren't here, the video still plays silent with captions, so nothing breaks.
